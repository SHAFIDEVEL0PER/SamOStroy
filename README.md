# SamOStroy — Сайт строительной компании

**SamOStroy** — профессиональная строительная компания, специализирующаяся на возведении частных и коммерческих объектов под ключ. Наш сайт предоставляет клиентам удобный интерфейс для знакомства с услугами, проектами и контактами компании.

## 🔨 Основные функции сайта

- 📌 **Главная страница** с ключевыми услугами и преимуществами компании, а также обращение руководителя и отзывы.
- 🏗 **О компании** с информацией про каждого сотрудника и описание компании.
- 📝 **Построенные дома** уже созданные здания с описанием каждого кирпичика.
- 📞 **Контакты** телефон, телеграмм и вк.

## 🛠 Технологии

- **Frontend**: HTML5, CSS3, JavaScript
- **Дизайн**: Адаптивная верстка
- **Дополнительно**: Google Maps для контактов
